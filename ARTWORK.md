# Изображения персонажей

Персональные спрайты подготовлены с помощью генерации изображений для этой игры. Фотографии служили референсами внешности; исходные фотографии в репозитории отсутствуют. Персонажи имеют прозрачный фон и стилизацию под ретро-платформер.

| Файл | Роль в игре |
| --- | --- |
| `dist/assets/oleg.png` | Игровой герой |
| `dist/assets/zhenya.png` | Персонаж у замка |
| `dist/assets/baget.png` | Спутник на московской прогулке |
| `dist/assets/sasha.png` | Спутница на втором уровне |
| `dist/assets/sasha-wave.png` | Прощальный кадр второго уровня |

Персональные изображения и скриншот `docs/gameplay.png` не входят в лицензию MIT для кода. Условия описаны в [ASSET_USAGE.md](ASSET_USAGE.md).
